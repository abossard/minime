# Principle: decide with data

When you face a choice (approach, tool, root cause), do not decide from memory or plausibility.

- First check whether the environment, the code, the docs, or a quick command can decide it. Gather the fact, then decide.
- State the fact that decided each nontrivial choice in one line: `DECISION: <choice> BECAUSE <observed fact>`.
- If no fact is obtainable, pick the smallest reversible option and label the decision `FACT-FREE`.
